\# Uso de Inteligencia Artificial



Durante el desarrollo de la API MiniBlog se utilizó Inteligencia Artificial como herramienta de apoyo para el aprendizaje y desarrollo del proyecto.



\## Usos realizados



La IA fue utilizada para:



\- Comprender la estructura de una API REST con Node.js y Express.

\- Resolver dudas sobre la conexión entre Node.js y PostgreSQL.

\- Revisar y corregir errores durante el desarrollo.

\- Recibir orientación sobre la organización de carpetas y archivos.

\- Generar ejemplos de consultas SQL y endpoints.

\- Ayudar en la creación de tests utilizando Jest y Supertest.

\- Revisar la documentación del proyecto y generar la documentación OpenAPI.

\- Mejorar la redacción del README.



\## Proceso



Las sugerencias proporcionadas por la IA fueron revisadas y adaptadas al proyecto antes de ser implementadas.



Se realizaron pruebas manuales y automatizadas para comprobar el funcionamiento de la API.



\## Herramienta utilizada



\- ChatGPT



\## Consideración final



La Inteligencia Artificial fue utilizada como herramienta de apoyo y aprendizaje. La implementación final fue realizada, revisada y probada durante el desarrollo del proyecto.
